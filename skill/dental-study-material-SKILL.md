# Dental Study Material — Compilation Rules

This is a standing content-sourcing, organization, and formatting contract for this user's dental study material. Apply it every time, regardless of which module or topic is requested.

## 0. Module structure (fixed)

All study material slots into this existing 3-module system. Do not invent a different structure unless the user explicitly asks to reorganize it.

- **Module 1 — Conservative & Restorative Dentistry** (7 sub-modules: Caries Science & Prevention; Tooth Preparation & Operative Dentistry; Restorative Materials & Selection; Direct Restorations; Indirect Restorations; Special Situations & Challenges; Evidence-Based Practice & Outcomes)
- **Module 2 — Endodontics** (8 sub-modules: Pulp-Dentin Complex Biology; Endodontic Diseases & Pathology; Endodontic Diagnosis & Examination; Nonsurgical Treatment; Surgical Endodontics; Special Endodontic Situations; Vital Pulp Therapy & Regenerative Endodontics; Endodontic Outcomes & Management)
- **Module 3 — Dental Materials & Material Science** (7 sub-modules: Fundamental Material Science; Mechanical Properties; Material Classification & Composition; Adhesive Systems & Bonding; Cements & Luting Agents; Biocompatibility & Bioactive Materials; Material Selection & Degradation)

If a request falls outside these three modules (e.g., Periodontics, Prosthodontics, Oral Pathology), ask the user whether to add it as a new module before proceeding.

Even with standing textbooks locked in, always confirm before compiling:

2. Anything narrower than the standing default list (e.g., "just use Ingle for this one, skip Cohen").
3. **Deliverable style — STANDING DEFAULT as of the Module 2 Sub-Module 1 build: a deliberate BLEND of flowing prose and notes format, applied topic-by-topic within the same document, extensive and exhaustive in depth.** The user explicitly asked for this to apply to every sub-module going forward, in every module — stop asking which style is wanted; this is now the default the way the standing textbook lists are defaults. Concretely:
   - **Flowing prose** for mechanism/process-heavy passages — pathophysiology, named theories/mechanisms, cascades, anything where the reasoning chain (why X causes Y causes Z) is the actual content, not just a fact to list. Write these as continuous paragraphs that walk through the mechanism, not as chopped-up bullets that lose the causal thread.
   - **Notes format** (headers, bullet points, bold "DEFINITION —" call-outs, comparison/summary tables) for classification-heavy passages — anatomy inventories, named classification systems, quantified data tables, lists of types/categories, anything a reader would want to scan or revise from rather than read as an argument.
   - Both fully sourced with page-cited Vancouver references throughout, at the same rigor either way — the format changes, the citation discipline doesn't.
   - "Extensive and exhaustive" means: do not compress a topic to fit a target length, and do not treat one good source as sufficient once the standing textbook list names several — mine each relevant chapter across every applicable source (per the "use ALL confirmed-available textbooks" and "grep every extracted textbook" rules below) before writing, the way Sub-Module 1 of Module 2 drew on six sources across three sub-sections rather than stopping at the first primary text.

   - Sources may still be visibly tiered (Textbook → Authoritative body → DCNA) or blended by topic with the same priority discipline applied internally — that choice is independent of the prose/notes blend and can still be asked about if genuinely unclear from context.

2. **Formal definitions/classifications next — from the relevant authoritative body where one exists, otherwise from the textbook itself:**
   - Endodontics topics → **AAE** (American Association of Endodontists) glossary/position statements.
   - Conservative & Restorative topics → **ADA**. Prefer a real, specific ADA output over a generic glossary entry when one exists for the topic — e.g., an ADA evidence-based clinical practice guideline (with its GRADE recommendation tables) or an ADA classification system (e.g., the ADA Caries Classification System, ADA CCS) is far more useful than a one-line glossary definition, and should be actively searched for and used in full (tables included) when the topic is guideline/classification-shaped.
   - Dental Materials topics → **ISO/FDI** terminology and standards where the term is standardized.
   - If the authoritative body doesn't cover a given term, fall back to the standard textbook's own definition — don't leave a concept undefined.
   Every major concept/entity introduced should have a formal definition sourced this way before further explanation continues, not buried mid-paragraph/mid-section.
3. **Supporting/supplementary data last — from DCNA (Dental Clinics of North America) articles or other journal sources.** Use these to add contemporary evidence, nuance, or data (success rates, newer materials, emerging techniques) the textbook doesn't cover or predates. Clearly positioned as supplementary, not as the primary explanation of a concept.

A reader should always be able to tell that the core explanation came from the textbook, the term/classification was formally defined via the authoritative body (or textbook, if no authoritative source exists), and the extra evidence came from a journal — whether that's done with visibly separated tier headers, or blended by topic with each fact's own citation still making the tier traceable (both are acceptable deliverable styles — see Step 0.5.3).

## 3. Sourcing discipline (non-negotiable)

- **Read the actual source PDFs page-by-page** before writing — do not write from general knowledge and retrofit citations. If a PDF can't be parsed (missing `pdftotext`/poppler etc.), install what's needed (e.g., `pip install pymupdf`) rather than falling back to unsourced writing.
- **Every factual claim gets an in-text Vancouver citation with the exact page number** of the source it came from: `[n, p.X]`, where `n` indexes a numbered reference list at the end of the document. Page numbers must be the real page the fact appears on, not a guess or chapter-level approximation. This is locked as-is — do not change citation style without being asked.
- Flag explicitly, in the text, anywhere a source itself presents a point as debated, evolving, or contested — don't smooth this into settled fact.
- If a Google Drive link or new library is given, check it before assuming what's available; also check the user's local filesystem (files may already be downloaded — check before re-fetching from Drive).
- **Before delivering, verify the reference list numbering is internally consistent** — every `[n, ...]` used in the body must point to the source actually numbered `n` in the reference list (a real bug caught during the 1.2 run: a DCNA article was miscited as `[4]`, the ICDAS chapter's number, instead of its own `[6]`).
