## STUDY MODE

### 1. Why preoperative planning matters more for Class IV
Occlusal assessment is MORE critical for Class IV than other classes, since it directly dictates both preparation-margin placement (into non-contact areas where possible) and the retention/resistance-form features needed — heavy occlusion requires more boxlike, resistance-form-heavy geometry with wider bevels and possible groove retention [SRC, Sturdevant's p.550]. For large lesions/fractures, a PREOPERATIVE IMPRESSION can be taken before treatment begins specifically to serve as a template for the eventual restoration's contours [SRC, p.550].

### 2. Tooth preparation
A conservative enamel bevel is placed at the margin (except where a matrix constrains this, per the Class II exception already noted elsewhere in this topic — Class IV, lacking a circumferential matrix band, does not face the same resin-pooling problem). Shade should be selected BEFORE isolation/rubber dam placement, per the dehydration-trap rule (Section 4 below) [SRC, p.554].

### 3. Matrix technique — standard and custom lingual matrix
A standard polyester strip matrix is used for typical Class IV defects, but its flexibility genuinely makes contour control difficult, risking an over/under-contoured result or an open contact; CREASING the matrix at the lingual line angle corrects undercontouring there specifically. Preformed celluloid crown forms are NOT recommended (too thick for accurate control) [SRC, p.553]. For large/complex Class IV restorations, particularly when duplicating an EXISTING restoration's lingual contour, the CUSTOM LINGUAL MATRIX technique is used instead: (1) select shade before isolating/removing the old restoration; (2) take a silicone lingual/incisal index of the EXISTING contour before any tooth structure is removed; (3) place rubber dam, remove old material/caries, place a conservative bevel; (4) etch/prime/bond as usual; (5) reposition the lingual matrix and insert the FIRST composite increment against it in the lingual portion — this single increment generally establishes the lingual, proximal AND incisal contours of the entire restoration; (6) continue adding/curing further increments (dentin/enamel shades, tints for effects like blue opalescence between mamelon lobes) to complete the form [SRC, p.553-554]. The stated payoff: this technique reduces manual contouring/finishing needed afterward, since the lingual index does the shape-defining work [SRC, p.554].

### 4. Shade selection
Shade determination must be performed BEFORE rubber dam isolation, on clean, hydrated teeth, because dehydration makes teeth appear LIGHTER — full rehydration can take several hours [SRC, condensed from existing shade-matching study material]. A specific, memorable failure pattern: a correctly pre-selected shade will make the restoration look DARKER than the now-dehydrated tooth immediately after dam removal (expected, self-corrects over hours); if the restoration instead looks SIMILAR to the dehydrated tooth right after removal, the shade was probably chosen wrong and will mismatch once the tooth rehydrates [SRC]. Most manufacturers match shades to the VITA Classical guide (hue families A-D, varying by chroma/value); the newer VITA 3D-MASTER separates value, chroma and hue explicitly via a dichotomous decision method, determining value FIRST [SRC].

### 5. Layering (stratification) technique (condensed from Q9)
An opaque dentin-shade increment first replicates lost dentin anatomy (including dentin mamelons, the natural lobed projections visible through translucent enamel in younger teeth), followed by a more translucent enamel-shade increment replicating lost enamel — dentin-shade increments must NEVER reach the cavosurface margin, leaving room for the enamel layer to cover it [SRC, condensed from Q9]. An opaque "halo" filament along the incisal edge, matched to the tooth's own cervical shade, simulates the natural incisal opacity band [SRC, condensed].

### 6. Insertion and finishing
Composite is inserted in finer 1-2mm increments (reflecting incisal-edge load-bearing demands) [SRC, p.554]. Finishing follows the sequence established in Q7: coarse-to-fine graduated abrasive discs/points (NOT rubber points, shown to give the worst surface finish in McCabe's specific comparison — though note Michigan's own separate polishing table does not test an equivalent "rubber point" category, so this is correctly sourced to McCabe specifically, not a universal textbook consensus [composites/_AUDIT_2026-10-15.md A.12]), with the counter-intuitive, evidence-based option of delaying finishing to a later appointment to improve eventual wear resistance [SRC, condensed from Q7].

### 7. Cross-reference: when direct technique is insufficient (new, 2026-10-15 textbook audit)
For larger/more extensive Class IV defects, or where free-hand direct build-up risks an unsatisfactory incisal/proximal form despite the custom lingual matrix above, the "direct-indirect" (semidirect) technique described fully in Q08 is a documented alternative — sculpting the restoration on the unprepared/prepared tooth, removing it for a supplemental extraoral light-cure and heat-tempering step (raising degree of conversion), then adhesively luting it back — rather than finishing the entire restoration intraorally in one sitting [composites/_AUDIT_2026-10-15.md B; see Q08 for the full protocol]. This answer's own scope remains the direct, single-sitting technique described above; Q08 should be consulted for the semidirect alternative and the fuller composite-veneer-specific taxonomy.

The evidence directly contradicts this: shade MUST be selected before rubber dam isolation, since dehydration lightens the tooth and can take several hours to reverse — selecting shade after isolation produces a restoration that mismatches once the tooth rehydrates [SRC]. The defensible, examiner-rewarded point is the specific diagnostic pattern this produces: a correctly pre-selected restoration looks temporarily darker immediately after dam removal, while one that looks "right" immediately after removal was probably selected incorrectly `[Certain]`.

## EXAM MODE

**(Estimated writing time: ~31-36 min)**

### Introduction
Class IV restoration — replacing a fractured or missing incisal angle with composite — demands more careful preoperative planning than most other restoration classes, because the same preparation and matrix decisions directly determine both function and the highly visible esthetic outcome. This answer addresses tooth preparation, matrix technique, shade selection, layering, and finishing in the sequence a clinician actually encounters them.

### Tooth preparation and preoperative planning
Occlusal assessment matters more for Class IV than for other classes, since it directly determines both where the preparation margin should be placed — ideally into non-contact areas — and what retention and resistance-form features the preparation will need, with heavier occlusal contact requiring a more boxlike, retention-heavy design with wider bevels and possible groove retention. For large lesions or fractures, taking a preoperative impression before any tooth structure is removed provides a template for developing the eventual restoration's contours. A conservative enamel bevel is placed at the margin, and — critically, since it is easily forgotten once isolation begins — shade must be selected at this preoperative stage, before rubber dam placement, for reasons explained below.

### Matrix technique
A standard polyester strip matrix serves most typical Class IV defects, but its inherent flexibility genuinely makes contour control difficult, risking an over- or under-contoured restoration or an open proximal contact. Creasing or folding the matrix specifically at the lingual line angle corrects the single most common resulting error, undercontouring at that point, and preformed celluloid crown forms should not be used for Class IV, since they are too thick to permit accurate contour control. For larger or more complex Class IV restorations, particularly where an existing restoration's lingual contour is worth duplicating rather than re-sculpting from scratch, the custom lingual matrix technique is used instead. Shade is selected first, before isolation. A silicone index of the existing lingual and incisal contour is then taken before any tooth structure is removed. Rubber dam is placed, the old material and any caries or friable structure removed, and a conservative bevel placed. Etching, priming and adhesive application proceed as usual. The lingual matrix is then repositioned, and the first composite increment is inserted against it in the lingual portion of the preparation — a single increment that, once cured, generally establishes the lingual, proximal and incisal contours of the entire final restoration. Further increments, in dentin and enamel shades with tints added for effects such as blue opalescence between mamelon lobes, complete the build-up. This technique's genuine payoff is that it substantially reduces the manual contouring and finishing that would otherwise be needed, since the lingual index itself performs the shape-defining work.

### Shade selection
Shade determination must be carried out before rubber dam isolation, on clean, hydrated teeth, because dehydration makes a tooth appear lighter through reduced translucency, and full rehydration afterward can take several hours. This produces a specific, diagnostically useful pattern worth remembering precisely: if the shade was selected correctly before isolation, the finished restoration will look slightly darker than the now-dehydrated remaining tooth structure immediately after the rubber dam is removed, which is expected and will self-correct as the tooth rehydrates over the following hours. If, instead, the restoration looks similar to the dehydrated tooth immediately after removal, the shade selection was probably wrong, and the restoration will appear mismatched once the tooth itself lightens further. Most manufacturers match their shades to the VITA Classical guide, organised into four hue families varying by chroma and value, while the newer VITA Toothguide 3D-MASTER separates value, chroma and hue explicitly, determining value first through a dichotomous comparison method.

### Layering technique
Natural teeth are genuinely polychromatic, and this is reproduced by layering composites of different translucency to match the tissue each layer replaces. An opaque, dentin-shade increment is placed first to replicate the lost dentin's own anatomy, including its natural lobed mamelon projections, which remain visible through translucent enamel in younger teeth. A more translucent enamel-shade increment is then placed over this to replicate the lost enamel, with the specific rule that the dentin-shade increment must never be allowed to reach the cavosurface margin, deliberately leaving room for the enamel-shade layer to cover it. A thin opaque "halo" filament along the incisal edge, matched to the same shade as the tooth's own cervical region, completes the natural incisal-opacity effect.

### Finishing
Finishing proceeds through a coarse-to-fine graduated sequence of abrasive discs and points, specifically avoiding rubber points, which have been shown in quantified comparative testing to produce the worst surface finish of all common polishing methods despite their reputation for gentleness. A genuinely counter-intuitive, evidence-based option worth considering is delaying finishing to a later appointment rather than completing it immediately, since this has been shown to improve the restoration's eventual wear resistance by allowing the composite's degree of conversion to mature fully first.

### Conclusion
Successful Class IV composite restoration depends on treating preparation, matrix selection, shade determination, layering and finishing as one continuous, carefully sequenced process rather than five independent steps — in particular, selecting shade before isolation and choosing the matrix technique (standard with lingual-crease correction, or custom lingual matrix for complex cases) according to whether an existing contour is worth duplicating.

## HIGH-YIELD POINTS
- Occlusal assessment matters MORE for Class IV — directly dictates margin placement AND retention-form geometry.
- Custom lingual matrix: silicone index of EXISTING contour taken BEFORE removal; first increment establishes lingual/proximal/incisal contour together.
- Standard matrix fix: crease at the lingual line angle to prevent undercontouring; never use preformed celluloid crown forms.
- Shade BEFORE isolation — dehydration lightens teeth; correct shade selection makes the restoration look temporarily DARKER after dam removal, not matched.
- Layering: dentin-shade (with mamelons) NEVER reaches the cavosurface margin — enamel-shade layer must cover it.
- Finishing: graduated discs, NOT rubber points (worst finish); delayed finishing improves eventual wear resistance.

## COMMON EXAM MISTAKES
1. Selecting/describing shade determination as occurring after isolation — the dehydration trap makes this a real, examinable error.
2. Describing the custom lingual matrix technique without noting the index must be taken BEFORE removing the old restoration.
3. Omitting the lingual-line-angle crease correction for the standard matrix's undercontouring problem.
4. Allowing the dentin-shade layer to reach the cavosurface margin in a described layering sequence — this is explicitly wrong.

## MNEMONIC
**"SMILE"** for the five-step sequence: **S**hade (before isolation) → **M**atrix (standard+crease or custom lingual) → **I**ncremental layering (dentin-then-enamel) → **L**ingual contour established first → **E**vidence-based finishing (discs, not rubber points; consider delay).
