## STUDY MODE

### I. Bonding agents — classification and composition (condensed; full detail in CD_Q26)
Etch-and-rinse (3-step/2-step) vs self-etch (2-step/1-step) vs universal/multi-mode — classified by etch strategy. Composition: HEMA + Bis-GMA/UDMA + solvent + acidic functional monomer (self-etch/universal) + photoinitiator.

### II. Clinical techniques (the section this question specifically foregrounds)

**Total-etch (etch-and-rinse) technique, with real named-product timings (Summitt's Table 9-2, PDF p.441-448):** apply 30-40% phosphoric acid (15s/15s per Sturdevant's/Summitt's; Pickard's gives a different 10s dentin/20s enamel protocol — a real discrepancy) → rinse → dry enamel to frosty-white, keep dentin MOIST → apply primer/adhesive — e.g. **Scotchbond Multi-Purpose** (primer dry 5s, bond cure 10s), **Gluma Solid Bond** (primer 30s, bond cure 40s), **Gluma Comfort Bond** (three consecutive coats, 15s each, cure 20s) → light-cure → place restorative material. [SRC]

**Self-etch technique:** apply the self-etch primer (2-step) or all-in-one adhesive (1-step) directly to the smear-layer-covered surface, allow the required dwell time (manufacturer-specified, typically 10-20s) for simultaneous etch+prime, **no separate rinse step**, light-dry gently to evaporate solvent, apply separate adhesive resin (2-step systems only), light-cure.

**Selective-etch technique:** phosphoric acid applied to enamel margins ONLY for 15-20s, rinsed, enamel dried to frosty-white; self-etch primer or universal adhesive then applied to the entire preparation (both the etched enamel and the unetched dentin) per the self-etch protocol above — combining enamel's preference for aggressive etching with dentin's preference for gentler treatment.

**Technique for universal adhesives specifically:** can be used in any of the three modes above at the operator's discretion; manufacturer instructions specify whether "active" scrubbing-in application (improving monomer penetration, particularly into dentin) is required versus passive application.

**Indirect-restoration bonding technique — a real, named substrate-specific protocol table (Alani & Patel, PDF p.54):**
| Substrate | Protocol |
|---|---|
| Gold Type III | steam clean → alumina blast → (optional heat treat) → alcohol clean → alloy 10-MDP primer → cement |
| Ni/Co-Cr alloy | same, no heat-treat step |
| Composite resin (indirect) | steam clean → alumina blast → alcohol clean → adhesive → cement |
| Resin nano-ceramic | alumina blast with **CoJet-Sand** → alcohol clean → adhesive → cement |
| Glass ceramic (feldspathic/lithium disilicate) | steam clean → **5-9.5% HF, 10/20/60s** → rinse → a SECOND, 37% phosphoric-acid etch (15s) → alcohol clean → silane 60s → cement |
| Zirconia | steam clean → alumina blast (NOT HF, NOT silane) → alcohol clean → **ceramic 10-MDP primer, 60s** → cement |
Alumina-blast parameters generally: 20-50µm particle size, 30-45 PSI. [SRC]

### III. Factors governing technique choice
Substrate (enamel vs dentin vs both; sound vs sclerotic/caries-affected dentin), restoration type (direct composite vs indirect bonded restoration vs core build-up vs fiber post), operator moisture-control confidence, and postoperative-sensitivity risk profile of the specific case — see this topic's CD_Q23 for substrate-specific technique modifications in detail.

- This question specifically rewards STEP-BY-STEP clinical technique detail, not just materials classification.
