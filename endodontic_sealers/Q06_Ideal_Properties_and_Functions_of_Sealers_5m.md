## STUDY MODE

### Functions (Berman et al, 2021, via digest)
- Fill the space between canal wall and core.
- Fill voids, irregularities, lateral and accessory canals.
- Fill interstices between cones in lateral compaction.
- Lubricate cone placement.
- Provide the seal, since gutta-percha does not adhere (Gatewood, 2007).
- Entomb remaining irritants and contribute to a fluid-tight seal.

### Ideal properties (Grossman; Gatewood, 2007)
Tacky when mixed (adhesion to wall and core); hermetic seal; radiopaque; no shrinkage on setting; does not stain tooth; bacteriostatic or at least not encouraging bacterial growth (more antibacterial effect increases host toxicity); slow set (working time and post-space preparation); insoluble in tissue fluids; tissue tolerant (more toxic unset); soluble in a common solvent for retreatment. No sealer has all of them (Gatewood, 2007).

Caution: radiopacity is not sealing; very radiopaque sealers can mask voids (Berman et al, 2021, via digest).

## EXAM MODE
**(Word count about 190; about 8 min)**

### Functions
Fills space between canal wall and core; fills voids and lateral canals; fills gaps between cones; lubricant for cone seating; produces seal; entombs irritants.

### Ideal properties (Grossman)
| Property | Reason |
|---|---|
| Tacky | Adhesion to wall and core |
| Hermetic seal | Prevents leakage |
| Radiopaque | Visible on radiograph |
| No shrinkage | No gaps |
| No tooth staining | Esthetics |
| Bacteriostatic | Does not support bacteria |
| Slow set | Working time |
| Insoluble | Stability |
| Tissue tolerant | Periapical healing |
| Soluble in a solvent | Retreatment |

### Remark
No sealer meets all properties; radiopacity does not equal seal.
